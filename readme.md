# Test Task Yandex Wev Dev

Тестовое задание по вёрстке лендинга.

## Установка
```sh
# Установка зависимостей
npm i
```

## Запуск
```sh
npm run dev
```

## Сборка
```sh
npm run build
```

## Преимущества
- Сборка с помощью **vite**;
- Использование `.webp` вместо `.png`;
- Ведение истории изменений в гите с тасками и этапами;
- Разделение стилей и исполняемого кода по смыслу и предназначению;
